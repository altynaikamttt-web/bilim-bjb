# Bilim — Информатика БЖБ / ТЖБ · 5–9 сынып

**GitHub Pages + Supabase нұсқасы. Python қажет емес.**

Оқушы сайт сілтемесі арқылы жұмысты орындайды. Нәтиже Supabase дерекқорына сақталып, мұғалім кабинетінде көрінеді. GitHub тек сайт файлдарын орналастырады. Алдымен төмендегі бір реттік баптау қажет: архивті жүктеу ғана жеткіліксіз.

## 1. Supabase жобасын жасау

1. https://supabase.com/dashboard ашып, аккаунтпен кіріңіз.
2. **New project** басып, жоба жасаңыз. Дерекқор құпиясөзін өзіңізде сақтаңыз; оны сайт файлдарына жазбаңыз.
3. Жоба дайын болғанда **SQL Editor → New query** ашыңыз.
4. Осы жинақтағы **setup.sql** файлының барлық мәтінін қойып, **Run** басыңыз.
5. Бұл әрекет жабық кестелерді, тексеру қызметін және 5 үлгі БЖБ-ны жасайды. Қайта орындау бұрынғы жұмыстарды өшірмейді.

## 2. Мұғалім аккаунты

1. Supabase ішінде **Authentication → Users → Add user / Create new user** ашыңыз.
2. Өзіңіздің email және құпиясөзіңізді енгізіңіз. Email-ді расталған күйде жасаңыз (Auto Confirm User қолжетімді болса, қосыңыз).
3. **teacher-access.sql** файлын ашып, `teacher@example.com` орнына сол email-ді жазыңыз.
4. Өзгертілген SQL мәтінін **SQL Editor** ішінде орындаңыз.
5. Мұғалімнің құпиясөзін GitHub-қа, SQL-ге немесе config.js файлына енгізбеңіз. Оқушыларға аккаунт ашу қажет емес.

Қосымша мұғалімге рұқсат бергіңіз келсе, 2-қадамды оның email-імен қайталаңыз. Бұл бір мектептің ортақ кабинеті: рұқсаты бар барлық мұғалімдер барлық жұмысты және нәтижені көреді. Бөлек мектептерге бөлек Supabase жобасын пайдаланыңыз.

## 3. Сайтты дерекқорға қосу

Supabase жобасынан **Connect** немесе **Project Settings → API / API Keys** бөлімін ашыңыз. Екі ашық мән керек:

- **Project URL**: `https://...supabase.co`
- **Publishable key** (`sb_publishable_...`) немесе ескі **anon public key**.

**Secret (`sb_secret_...`) және service_role кілтін қолданбаңыз.** Олар сайтқа да, GitHub-қа да салынбайды.

`config.js` файлын мәтіндік редакторда ашып, екі мәнді ауыстырыңыз:

```js
window.BILIM_CONFIG = {
  url: "https://YOUR-PROJECT.supabase.co",
  anonKey: "YOUR_PUBLISHABLE_OR_ANON_KEY"
};
```

Немесе сайттың алғашқы баптау экранында екі мәнді енгізіп, **config.js файлын жүктеу** батырмасын басыңыз. Жүктелген файлды репозиторийдегі config.js орнына салыңыз. Мәндер тек сол браузерде сақталып қалмайды: барлық оқушыға ортақ болуы үшін файлды GitHub-та жаңарту міндетті.

## 4. GitHub-қа жүктеу

1. Архивті ашыңыз. ZIP файлының өзін емес, ішіндегі файлдарды жүктеңіз.
2. Репозиторий → **Add file → Upload files**.
3. **index.html**, **config.js**, **README.md**, **setup.sql**, **teacher-access.sql** файлдарын жүктеп, **Commit changes** басыңыз. index.html түбірде, қосымша ішкі буманың ішінде емес, тұруы керек.
4. Ескі Python нұсқасындағы файлдарды қолданбаңыз. Егер репозиторийде оқушы дерегі бар `bilim.sqlite3` кездессе, жарияламаңыз.
5. **Settings → Pages → Source: Deploy from a branch**.
6. **Branch: main**, **Folder: / (root)** → **Save**.
7. GitHub орналастыруды аяқтаған соң **Visit site** арқылы ашыңыз.
8. Баптау экраны әлі көрінсе, config.js дұрыс жаңартылғанын тексеріп, бетті Ctrl+F5 арқылы жаңартыңыз.

GitHub Pages баптауы: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
Supabase кілттері: https://supabase.com/docs/guides/getting-started/api-keys

## 5. Алғашқы тексеру

1. Сайтта **Мұғалімге кіру** басып, 2-бөлімдегі email және құпиясөзбен кіріңіз.
2. Бір үлгі жұмысты қарап, содан кейін **Шығу** басыңыз.
3. Басқа браузерде немесе басқа компьютерде оқушы ретінде бір үлгі жұмысты орындаңыз.
4. Мұғалім кабинетіне оралып, **Оқушы нәтижелері → Жаңарту** басыңыз.
5. **Толық есеп → Басып шығару / PDF** арқылы оқушының әр жауабын және балдарын алыңыз.
6. Бірнеше компьютерден тексерген соң сыныпқа сайт сілтемесін беріңіз. Компьютерлер бір жергілікті желіде болуға міндетті емес, интернет керек.

## Мүмкіндіктер

- 5–9 сынып бойынша сүзу; БЖБ және ТЖБ құрастыру.
- Таңдау сұрақтары және қысқа жауаптар; жауап баламалары `|` арқылы енгізіледі.
- JSON импорт/экспорт. Мұғалімдегі «JSON сақтау» батырмасы формат үлгісін береді.
- Word/PDF тапсырмаларын автоматты тану жоқ. Құрастырушы арқылы енгізіңіз.
- Таймер, серверде тексеру және уақыт шегін бақылау.
- Жеке жауаптар, балдар, пайыздар, орындау ұзақтығы; PDF басып шығару және CSV экспорт.
- Жұмыс жіберілгеннен кейін өзгермейді. Қайта жіберу бұрынғы нәтижені қайтарады.
- Аяқталмаған жұмыс сол қойындыда уақытша сақталады. Оқушы терезені жаппауы керек.
- Есептер «Жаңарту» батырмасымен жүктеледі, автоматты жаңарту жоқ.

## Бағалау және шектеулер

Дұрыс жауапқа толық балл, басқасына 0. Қысқа жауаптарда әріп регистрі және артық бос орын ескерілмейді. Мағынасы ұқсас еркін мәтінді немесе программаның сапасын тексеру жоқ. Уақыт лимитіне жіберу үшін 15 секунд қосылады; одан кеш түскен жұмыс сақталады, бірақ балл 0 болады. Тоқсандық баға есептелмейді.

Бастапқы 5 жұмыс — әр сыныпқа 5 тапсырмадан авторлық **ҮЛГІ**. Ресми немесе толық оқу бағдарламалық жинақ емес. Үлгі жауаптары setup.sql ішінде ашық: оларды құпия бақылау жұмысы ретінде қолданбаңыз. Өз нақты тапсырмаларыңызды сайттағы мұғалім құрастырушысымен қосыңыз; олардың жауап кілттерін репозиторийге жүктемеңіз.

Оқушы аты-жөнін өзі енгізеді. Бұл нұсқада оқушы аккаунттары, бір реттік кодтар, қайта бастауға шектеу және античит жоқ; мұғалім қатысуды ұйымдастырады. Жоба сілтемесі бар адам ашық жұмысты бастай алады. Сабақтан соң жұмыстарды «Жабу» ұсынылады. Бұл ірі ашық емтихан жүйесі емес, мектептік ортақ бағалау құралы.

Оқушының жеке есебі, жауаптары және толық жауап кілттері жабық дерекқор кестелерінде. Оқушыға тек өзінің кездейсоқ жұмыс идентификаторы мен тапсырма мәтіні беріледі; сол идентификатор тек өз нәтижесін жіберуге/алуға мүмкіндік береді. Оны басқаға бермеңіз. Мұғалім аккаунты Supabase Auth арқылы тексеріліп, қосымша жабық рұқсат тізімімен шектеледі.

Қызмет Supabase қолжетімділігіне және жобаның тарифтік лимиттеріне тәуелді. Дерекқор қосылмайынша ортақ сақтау жұмыс істемейді. Оқушы деректері Supabase жобасында сақталады; мектептің деректерді сақтау тәртібіне сай пайдаланыңыз.

## Қате шықса

- **Онлайн дерекқор қосылмаған**: config.js ішіндегі URL/ашық кілтті толтырып, GitHub-қа жаңартыңыз.
- **Failed to fetch**: интернетті, URL-ді, жобаның іске қосылғанын тексеріңіз.
- **Could not find function bilim_api**: setup.sql толық орындалмаған немесе дерекқор API схемасы жаңармаған. SQL соңындағы `notify pgrst, 'reload schema';` пәрменін орындаңыз.
- **Invalid login credentials**: Authentication → Users ішіндегі email/құпиясөз және email расталғанын тексеріңіз.
- **Мұғалім құқығы берілмеген**: teacher-access.sql ішіндегі email-ді дұрыстап орындаңыз.
- **JWT expired**: қайта кіріңіз; қалыпты жағдайда сессия автоматты ұзартылады.
- **404**: index.html репозиторий түбірінде тұрғанын және Pages жариялауы аяқталғанын тексеріңіз.

## Құрылымы

- `index.html`: сайт және қазақ тіліндегі интерфейс; сыртқы JS кітапханалары қажет емес.
- `config.js`: жоба URL-і және жариялауға болатын API кілті.
- `setup.sql`: жабық кестелер, серверлік тексеру және жалпыға белгілі үлгі тапсырмалар.
- `teacher-access.sql`: нақты аккаунтқа мұғалім құқығын беру.
- `README.md`: осы нұсқаулық.

setup.sql және teacher-access.sql сайтта автоматты орындалмайды: тек Supabase SQL Editor ішінде іске қосылады. HTML/JS синтаксисі мен дерекқор логикасының жергілікті тексеру нәтижелері VALIDATION.md ішінде берілген. Сіздің жеке Supabase жобаңызда және GitHub-та орналастырудан кейін 5-бөлімдегі тексеруді орындаңыз.
